# CurtiPay Assistant

Painel simples e responsivo para organizar manualmente tarefas e valores relacionados ao CurtiPay.

## Recursos
- Cadastro de tarefa, link, tipo e valor.
- Abertura manual de links.
- Registro manual de conclusão.
- Resumo de tarefas concluídas e ganhos informados.
- Filtro por tarefas pendentes e concluídas.
- Exportação JSON e armazenamento local no navegador.

## Uso
Abra `index.html` em um navegador ou publique o repositório usando GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).

## Limites
Este projeto não entra na conta do CurtiPay, não segue perfis, não curte publicações nem confirma tarefas automaticamente. Não informe sua senha neste painel. Os dados ficam no armazenamento local do navegador; exporte um backup antes de limpar os dados do navegador.

## APK
O repositório contém a versão web. Para gerar um APK, será necessário adicionar um invólucro Android (por exemplo, Capacitor) e configurar uma compilação Android via GitHub Actions.
